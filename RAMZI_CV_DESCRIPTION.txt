[ ج. الوصف الكامل لصفحة تفاصيل المشروع (Detailed Portfolio / Case Study) ]

نبذة عن المشروع:
"رمزي" هو أداة إنتاجية مفتوحة المصدر تم تطويرها لمعالجة واحدة من أكثر المهام الروتينية استهلاكاً للوقت لدى مطوري التطبيقات والألعاب: إنشاء وتعديل وتصدير أيقونات التطبيقات بمقاسات وصيغ معقدة ومختلفة لكل نظام تشغيل.

المشكلة التي يحلها:
كل منصة (Android, iOS, Windows, macOS, Linux, وغيرها) تفرض قيوداً دقيقة على شكل الأيقونة، كثافة البكسل، ملفات التعريف (Manifests/XML/JSON)، والطبقات (مثل Adaptive Icons في أندرويد). الاعتماد على الأدوات التقليدية أو مواقع الويب الخارجية يعرض الخصوصية للخطر وغالباً ما يفتقر إلى إمكانية الضبط الدقيق لكل منصة بمعزل عن الأخرى.

الحل وأبرز المميزات:
1. معاينة حية ومطابقة للواقع (Live Multi-platform Simulator):
   معاينة تفاعلية فورية للأيقونة داخل أقنعة الأنظمة الحقيقية (دائري، squircle، أيقونات تكيفية، وغيرها).
2. تخصيص مستقل لكل منصة (Per-platform Independent Control):
   التحكم الكامل في حجم الطبقة الأمامية، الإزاحة (Offset)، التدوير، ونمط الخلفية (لون ثابت أو تمويه ضبابي للصورة) لكل منصة على حدة دون التأثير على المنصات الأخرى.
3. دعم 11 منصة ومحرك ألعاب بدقة واحترافية:
   - Android: الأيقونات التكيفية، الأيقونات الدائرية والتقليدية، ملفات XML، وأيقونة متجر Play (512x512).
   - iOS: حزمة AppIcon.appiconset كاملة مع ملف Contents.json الدقيق.
   - macOS: ملف AppIcon.icns بجميع المقاسات من 16 إلى 1024 بكسل.
   - Windows: ملف app_icon.ico متعدد الدقات مدمج في ملف واحد (16 إلى 256 بكسل).
   - Linux: شجرة مجلدات hicolor القياسية لكافة الكثافات.
   - المنصات الإضافية: watchOS, tvOS, Android TV.
   - محركات الألعاب: Godot, Unity, Unreal Engine.
4. هندسة واجهات متكيفة (Adaptive Multi-form Factor):
   - سطح المكتب: استوديو متكامل بثلاثة ألواح (Three-pane Studio)، شريط جانبي، مفتش خصائص قابل لتعديل العرض، واختصارات سريعة للوحة المفاتيح.
   - الويب: تجربة تفاعلية تدعم سحب وإفلات الصور وتنزيل النتائج كأرشيف ZIP فوري.
   - الهاتف: واجهة عمودية مخصصة للتحكم باللمس والتنقل التبويبي.
5. الخصوصية والأداء المحلي (Offline-first & Privacy):
   معالجة وتحويل الصور وتوليد الحزم يتم محلياً بنسبة 100% على جهاز المستخدم دون أي استدعاءات خادومية أو تتبع.
6. تدويل وتوطين شامل (Internationalization):
   دعم متقن لاتجاه الكتابة من اليمين لليسار (RTL) للعربية والإنجليزية (LTR)، ودعم الوضعين الليلي والنهاري ومظهر النظام.
7. هندسة التحزيم والنشر (DevOps & Packaging):
   إعداد سكربتات تحزيم أصلية لنظام لينكس تشمل حزم Flatpak, DEB, RPM, Arch, AppImage.

[ C. In-Depth Portfolio Case Study ]

Overview:
Ramzi is an open-source developer utility created to streamline the tedious and error-prone process of generating platform-specific application icons and assets.

The Problem:
Every operating system and game engine imposes unique icon guidelines, resolution requirements, folder structures, and metadata conventions (e.g., Apple's Contents.json, Android's adaptive XML vectors, Windows multi-resolution ICOs, macOS ICNS). Typical web-based generators compromise privacy, require internet access, and apply rigid global transformations that frequently distort branding.

Key Features & Engineering Highlights:
1. True-to-Life Simulation:
   Real-time live previews within actual operating system masks (squircle, circle, rounded rect, Android adaptive masks).
2. Per-Platform Granular Tuning:
   Fine-tune foreground scaling, offsets (X/Y), rotation, and background modes (solid color or blurred source background) independently without altering configurations for other targets.
3. 11 Target Platforms Supported:
   - Apple Ecosystem: iOS (AppIcon.appiconset + Contents.json), macOS (.icns 16-1024px), watchOS, tvOS.
   - Android & TV: Adaptive icon layers, legacy/round icons at all densities (mdpi-xxxhdpi), XML descriptors, and Google Play 512x512 store assets.
   - Desktop: Windows (multi-resolution .ico), Linux (freedesktop hicolor PNG hierarchy).
   - Game Engines: Godot, Unity, Unreal Engine ready structures.
4. Adaptive Multi-Form-Factor Architecture:
   - Desktop Studio: 3-pane layout (navigation sidebar, center preview stage, resizable inspector) with rich keyboard shortcuts.
   - Web App: Responsive browser experience with native drag-and-drop image import and client-side ZIP packaging.
   - Mobile: Touch-first single-column layout with smooth tabbed workflow.
5. 100% Offline & Privacy-Preserving:
   Zero tracking, zero analytics, zero network requests. All pixel transformations and archive generation happen client-side.
6. Internationalization & Polished UX:
   Flawless RTL & LTR support (Arabic & English), light/dark/system themes, and screenshot preview framing tools.
7. Deployment & Tooling:
   Includes automated packaging shell scripts for modern Linux distributions (Flatpak, AppImage, DEB, RPM, PKGBUILD).
