# resources/web

Ramzi's own web (PWA) icon integration assets live in the build tree:

- `web/icons/` — PWA icons (including maskable variants)
- `web/favicon.png`
- `web/manifest.json` — background/theme colors

They are generated by `flutter pub run flutter_launcher_icons` using
`flutter_launcher_icons.yaml` (see PROJECT_NOTES.md). Do not edit them
manually — regenerate instead.
