# resources/ios

Ramzi's own iOS app-icon integration assets live in the build tree:

- `ios/Runner/Assets.xcassets/AppIcon.appiconset/` — full size matrix
  (opaque, no rounded corners; iOS applies the mask itself)

They are generated by `flutter pub run flutter_launcher_icons` using
`flutter_launcher_icons.yaml` (see PROJECT_NOTES.md). Do not edit them
manually — regenerate instead.
