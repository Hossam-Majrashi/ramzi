# resources/android

Ramzi's own Android launcher-icon integration assets live in the build tree:

- `android/app/src/main/res/mipmap-*/` — legacy + round icons
- `android/app/src/main/res/mipmap-anydpi-v26/` — adaptive icon XML
- `android/app/src/main/res/values/colors.xml` — `ic_launcher_background`

They are generated by `flutter pub run flutter_launcher_icons` using
`flutter_launcher_icons.yaml` (see PROJECT_NOTES.md). Do not edit them
manually — regenerate instead.
