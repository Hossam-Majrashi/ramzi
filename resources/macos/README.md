# resources/macos

Ramzi's own macOS app-icon integration assets live in the build tree:

- `macos/Runner/Assets.xcassets/AppIcon.appiconset/` — full size matrix
  (16 → 1024, @1x/@2x)

They are generated by `flutter pub run flutter_launcher_icons` using
`flutter_launcher_icons.yaml` (see PROJECT_NOTES.md). Do not edit them
manually — regenerate instead.
